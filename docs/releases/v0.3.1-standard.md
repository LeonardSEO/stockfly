# StockFly v0.3.1-standard — patch prerelease preparation

Prepared locally; publication remains pending. This patch keeps the exact `v0.3.0-standard` Bio Full seed 45 and Max Full seed 43 checkpoints, scientific evidence, failed causal status and negative playing-strength result. It changes only the native model installer's network behavior: GitHub API, manifest and asset requests now share one HTTP agent with a 15-second connection deadline, 30-second request/response deadlines and a 30-minute end-to-end/body ceiling per request.

The change was prompted by a live verification attempt in an environment that blocks outbound TCP from newly built Rust binaries while allowing `curl`, Python and `nc`. `v0.3.0-standard` could wait indefinitely there. The patch makes that blocked connection fail clearly after the connection deadline; it does not bypass or claim to fix host networking policy. Successful live GitHub download by the native binary still requires a host that permits its outbound connection.

The server test suite and all eleven native installer fixtures pass. An independent review found no Critical or Important issues. macOS and Windows runtime artifacts must be rebuilt from the reviewed patch commit and pass their scoped smoke checks before this prerelease is published. The model-bearing macOS bundle will retain the exact two-model catalog and evidence bindings. The Windows bundle remains download-first; Windows model inference and DX12 parity are not claimed.
