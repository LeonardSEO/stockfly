# StockFly v0.3.1-standard — experimental patch prerelease

Published at [GitHub Releases](https://github.com/LeonardSEO/stockfly/releases/tag/v0.3.1-standard) as a prerelease from commit `a3f6ebda630b06d94956ec3b3dcec8ce506905d1`. Its 42 assets total 536,095,482 bytes. Before publication, every remote asset name, byte size and SHA-256 digest matched the local staging exactly. The content-addressed model manifest is 20,939 bytes with SHA-256 `6535d0a2a4a9b9a945dff27ebc6e57307f322a6c7895f6e20a9e4e34a60f86a2`.

This patch retains the exact `v0.3.0-standard` Bio Full seed 45 and Max Full seed 43 checkpoints, scientific evidence, failed causal status and negative playing-strength result. It changes the native model installer so GitHub API, manifest and asset requests share one HTTP agent with a 15-second connection deadline, 30-second request/response deadlines and a 30-minute end-to-end/body ceiling per request. A blocked connection now fails after its deadline instead of waiting indefinitely.

The change followed a live verification attempt in an environment that blocks outbound TCP from newly built Rust binaries while allowing `curl`, Python and `nc`. The patch bounds that failure; it does not bypass host networking policy. A successful native GitHub download still requires a host that permits the binary's outbound connection. The server suite and all eleven installer fixtures pass, and an independent review found no Critical or Important issues.

The release contains exactly two models:

- **Bio Full Standard seed 45:** 6,898 trials, checkpoint SHA-256 `5e2094743fe960f307d4a39647afbd05682e47867f3a4e771a24f9634d01b3c5`, causal acceptance **FAIL**.
- **Max Full Standard seed 43:** 5,649 trials, checkpoint SHA-256 `a10de3f743ba9b0a2f590ba2a19fae794c0da615facd54e1b88d1595cd1c0bd3`, causal acceptance **FAIL**.

The selected models lost all 200/200 low-node ladder games by checkmate, so there is no finite point Elo. Native parity passes the fixed 24-case Apple M4 Metal suite: all 408 state hashes and selected moves match. These results do not establish causal acceptance, playing-strength improvement, browser WebGPU parity or Windows DX12 parity.
