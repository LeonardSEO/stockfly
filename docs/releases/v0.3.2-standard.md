# StockFly v0.3.2-standard — experimental UI patch prerelease

Published at [GitHub Releases](https://github.com/LeonardSEO/stockfly/releases/tag/v0.3.2-standard) as a prerelease from commit `858a2538448d1825dd4e0894b9b400d428d843fe`. Its 42 assets total 536,105,336 bytes. Before publication, every remote asset name, byte size and SHA-256 digest matched local staging exactly. The content-addressed model manifest is 20,939 bytes with SHA-256 `f878ad836dde86e5bdf32d29ceeb8a3e5e501663c58eac533e78239f8391a64d`.

This release retains the exact `v0.3.1-standard` Bio Full seed 45 and Max Full seed 43 checkpoints, scientific evidence, failed causal status, negative playing-strength result and bounded native installer waits. The canonical catalog still contains exactly two models:

- **Bio Full Standard seed 45:** 6,898 trials, checkpoint SHA-256 `5e2094743fe960f307d4a39647afbd05682e47867f3a4e771a24f9634d01b3c5`, causal acceptance **FAIL**.
- **Max Full Standard seed 43:** 5,649 trials, checkpoint SHA-256 `a10de3f743ba9b0a2f590ba2a19fae794c0da615facd54e1b88d1595cd1c0bd3`, causal acceptance **FAIL**.

The Brain sidebar action now opens the large interactive MaleCNS view and Play closes it, with synchronized active navigation and keyboard focus. The inline point cloud is taller, the expanded view uses more of the viewport, and the camera and points make the real soma geometry easier to read. Simulated activation uses a documented quiet-to-active palette from dark blue through cyan and gold to coral. The rates, quantization, neuron geometry and inference are unchanged.

The ordinary play surface no longer displays checkpoint hashes or catalog paths. Model integrity validation remains mandatory in the loader and trace-verification paths; the compact status reports that integrity is verified. A live Chrome check exercised Brain/Play navigation and a real `browserwebgpu` move through all 16 simulation steps before the release build.

Both models retain the existing 200/200 low-node ladder checkmate losses, so there is no finite point Elo. Native parity retains the fixed 24-case Apple M4 Metal result with all 408 state hashes and selected moves matching. This release does not establish causal acceptance, playing-strength improvement, browser WebGPU numerical parity or Windows DX12 parity.
