# StockFly v0.3.2-standard — UI patch prerelease preparation

Prepared for publication from the reviewed UI patch. This release keeps the exact `v0.3.1-standard` Bio Full seed 45 and Max Full seed 43 checkpoints, scientific evidence, failed causal status, negative playing-strength result and bounded native installer waits.

The patch makes the sidebar Brain action open the large interactive MaleCNS view and makes Play close it again, with synchronized active navigation and keyboard focus. The inline point cloud is taller, the expanded view uses more of the viewport, and the camera and points make the real soma geometry easier to read. Simulated activation now uses a documented quiet-to-active palette from dark blue through cyan and gold to coral. The rates, quantization, neuron geometry and inference are unchanged.

The ordinary play surface no longer displays checkpoint hashes or catalog paths. Model integrity validation remains mandatory in the loader and trace-verification paths; the compact status now reports that integrity is verified.

The release must be rebuilt from the final source commit. The model-bearing macOS archive must pass its archive, source-integrity, catalog and route smoke. The download-first Windows archive must pass its native server and Chrome no-model smoke on the exact source commit before publication. All remote asset names, sizes and SHA-256 digests must match local staging before the draft becomes visible.
